# How To Use

Enable Fly From The GUI Toggle Or Press **F** To Toggle It.
~
### PC Controls

- **F** ~ *Fly / Unfly*
- **W / A / S / D** ~ *Move*
- **Q** ~ *Down*
- **E** ~ *Up*
- **LeftControl + F** ~ *Minimize / Expand*
~
### Custom Speed

The Default Speed Is **32 SPS**.
You Can Enter A Different Value In The Speed Box And The Current Speed Will Update After The TextBox Loses Focus.
~
### VehicleSeats

If You Sit In A **VehicleSeat** While Normal Fly Is Enabled, Dynamic Fly Will Automatically Switch To Vehicle Fly.

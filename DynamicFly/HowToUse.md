# How To Use

Enable Fly From The GUI Toggle Or Press **F** To Toggle It.
~
### PC Controls

- **F** ~ *Fly / Unfly*
- **W / A / S / D** ~ *Move*
- **Q** ~ *Down*
- **E** ~ *Up*
- **C** ~ *CFly / Uncfly*
- **LeftControl + M** ~ *Minimize / Expand*
- **LeftControl + T** ~ *Switch Themes*
- **LeftControl + X** ~ *Close Popup* 
~
### Custom Flight Speed

The Default Flight Speed Is **32 SPS**.
You Can Enter A Different Value In The Speed Box And The Current Speed Will Update It.
~
### VehicleSeats Flight

If You Sit In A **VehicleSeat** While Normal Fly Is Enabled, Dynamic Fly Will Automatically Switch To Vehicle Fly.

# Dynamic Fly

Dynamic Fly Is A Fly Script Made Around A Simple Idea: Keep The Flight System Simple While Giving It A Proper GUI And A Few Extra Features.
~
It Supports Normal Character Flight And VehicleSeat Flight, With Camera-Based Movement, Adjustable Speed, Light/Dark Mode, GUI Scaling, Dragging, Minimize / Expand And A Topbar Button.
~
The Default Flight Speed Is 32 SPS, And The Script Starts With Fly Disabled And The Light Theme Enabled.

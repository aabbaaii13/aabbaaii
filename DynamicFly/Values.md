# External Values

Dynamic Fly Creates Several **Instances** Alongside The Main GUI Which Can Be Changed Externally While The Script Is Running In The Background.
~
### Toggle Value

The **BoolValue** Controls The Current Fly State.

- `true` ~ *Fly Enabled*
- `false` ~ *Fly Disabled*

Changing Its `Value` Will Toggle The Flight System.
~
### Speed Value

The **NumberValue** Controls The Current Flight Speed.
Changing Its `Value` Will Update The Speed Used By The Flight System.
~
### GUI Scale

The **UIScale** Controls The Size Of The Main GUI.
Changing Its `Scale` Allows You To Make The GUI Smaller Or Larger Externally.
~
These Values Can Be Useful If You Want To Connect Dynamic Fly To **Your Own Keybinds, GUI Or Other Code** Without Needing To Deobfuscating The Entire Script.

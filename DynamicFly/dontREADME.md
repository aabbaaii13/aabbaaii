# External Values

Dynamic Fly Creates Several **Instances** Alongside The Main GUI Which Can Be Changed Externally While The Script Is Running In The Background.

~

### Toggle Value

The **BoolValue** Controls The Current Fly State.

- `true` ~ *Fly Enabled*
- `false` ~ *Fly Disabled*
- 
Changing Its `Value` Will Toggle The Flight System.

~

### Custom Speed Variable

The **getgenv()** Controls The Current Flight Speed.
Changing Its `Value` Will Update The Speed Used By The Flight System.

~

### Custom GUI Scale Variable

The **getgenv().DFLC.tscale --mobile or getgenv().DFLC.dscale --pc** Controls The Size Of The Main GUI.
Changing Its `Value (1-5 Max)` Allows You To Make The GUI Smaller Or Larger Externally.

~

These Values Can Be Useful If You Want To Have Dynamic Fly **Custom Keybinds Or Custom Values For Your Scripts** Without Needing To Deobfuscating The Entire Script.``
